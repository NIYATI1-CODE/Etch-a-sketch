# Etch-a-sketch

A browser-based Etch-a-Sketch drawing application built with HTML, CSS, and JavaScript.

## Features

- Draw by clicking and dragging across the grid
- Choose a custom drawing color with the color picker
- Generate random colors
- Reset the current drawing
- Create a new grid with a custom size
- Responsive and clean layout

## Built With

- HTML5
- CSS3
- JavaScript

## What I Practiced

- DOM manipulation
- Event listeners
- Creating and modifying DOM elements with JavaScript
- CSS Grid
- JavaScript functions and arrays
- Handling mouse events
- Working with input elements
- Basic UI design and layout

## How to Use

1. Open the application in your browser.
2. Click and drag across the grid to draw.
3. Use **Color Picker** to choose a drawing color.
4. Use **Random Colors** for random drawing colors.
5. Use **Reset** to clear the current drawing.
6. Use **New Grid** to create a new grid.
